日本語

Okure-nai とは

Okure-nai は、macOS のメニューバーから使えるアラームアプリです。手動で時刻を登録するほか、Google カレンダーと連携すると、当日の予定の開始時刻の2分前にアラームを自動設定できます。会議やアポイントに遅れないことを目的に開発しています。

主な機能

  • メニューバーからアラームの追加・一覧・ON/OFF
  • 指定時刻の2分前に通知（画面と通知センター）
  • Sign in with Apple によるアプリ利用の開始
  • Google カレンダー連携（任意）— 当日の予定に基づくアラームの自動設定
  • アプリ内からアカウントと端末内データの削除

Google カレンダー連携について

連携は任意です。許可する場合、本アプリは Google Calendar API の読み取り専用（calendar.readonly）スコープのみを使用し、当日の予定を取得してアラーム時刻を決定します。予定データを当方のサーバーに保存することはなく、連携に必要なトークン等はお使いの Mac 上にのみ保存されます。

データの取り扱い

当方は利用者アカウント用のバックエンドデータベースを運用していません。詳細は プライバシーポリシー をご覧ください。

English

About Okure-nai

Okure-nai is a menu bar alarm app for macOS. You can set alarms manually, or optionally connect Google Calendar so the app automatically schedules alarms two minutes before the start time of today’s events. The app is designed to help you avoid being late to meetings and appointments.

Main features

  • Add, list, and enable/disable alarms from the menu bar
  • Notifications two minutes before each scheduled time (on-screen alert and Notification Center)
  • Sign in with Apple to start using the app
  • Optional Google Calendar integration — automatic alarms based on today’s events
  • In-app account and on-device data deletion

How Google Calendar is used

Calendar integration is optional. When enabled, the app uses only the read-only Google Calendar API scope (calendar.readonly) to fetch today’s events and determine alarm times. Event data is not stored on our servers; OAuth tokens and related data are kept only on your Mac.

Data handling

We do not operate a backend user database. See our Privacy Policy for details.
