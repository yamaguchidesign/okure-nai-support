プライバシーポリシー（Okure-nai）

最終更新日: 2026年6月13日

山口翔平（以下「当方」）は、macOS アプリ「Okure-nai」（以下「本アプリ」）における利用者情報の取扱いについて、次のとおり定めます。

1. 収集する情報と利用目的

本アプリは当方のサーバーに利用者アカウントを保存しません。次の情報はお使いの Mac 上に保存される場合があります。

種類 内容 目的
Sign in with Apple Apple が払い出すユーザー識別子、初回に限りメールアドレス（設定した場合） アプリ利用の開始、App Store ガイドラインに沿ったログイン手段の提供
Google カレンダー連携 OAuth により取得したアクセストークン等、連携に必要なデータ。Google の権限画面で示される範囲のカレンダー予定の読み取り（readonly） 当日の予定に基づくアラームの自動設定
アラーム・設定 利用者が登録した時刻、アラーム音の ON/OFF、自動連携の ON/OFF 等 アプリ機能の提供

2. 第三者への提供・販売

当方は、Google ユーザーデータを含む上記のデータを第三者に販売、貸与、共有、移転または開示しません。広告配信、行動追跡、信用評価その他、本アプリの機能提供と無関係な目的にも使用しません。

Google カレンダー連携に必要な認証情報およびリクエストは、利用者の操作に基づき、本アプリと Google の OAuth サービス、OpenID Connect サービスおよび Google Calendar API との間で直接送受信されます。当方のサーバー、広告事業者、分析事業者、データ仲介業者その他の第三者には送信しません。法令により開示が義務付けられる場合を除き、その他の開示は行いません。

3. データの保護

Google ユーザーデータを含む機微なデータについて、次の保護措置を講じます。

  • Google との認証および API 通信には HTTPS（TLS）を使用し、通信中のデータを暗号化します。
  • OAuth トークン、取得した当日の予定および関連設定は利用者の Mac 内でのみ処理し、当方のサーバーには保存しません。
  • 本アプリは macOS App Sandbox 内で動作し、保存データへのアクセスは本アプリおよび利用者の macOS アカウントに制限されます。
  • Google Calendar API には読み取り専用権限を要求し、アラーム作成に必要な当日の予定だけを取得します。
  • Google カレンダー連携の解除時または「アカウントとデータの削除」の実行時に、本アプリが保存した OAuth トークンおよび関連データを端末から削除します。

4. Google OAuth

カレンダー連携時、Safari 等のブラウザで Google の認証画面が開きます。トークンの扱いは Google のポリシーも併せてご確認ください。連携を解除すると本アプリは保存したトークンを削除します。

5. Sign in with Apple の解除

Apple ID 側でアプリへのアクセスを取り消すには、Apple ID の管理から「サインインとセキュリティ」等をご利用ください。

6. アカウント・データの削除

本アプリの設定に「アカウントとデータの削除」があります。実行すると、本アプリがこの Mac に保存している Sign in with Apple の識別情報、Google 連携情報、全アラーム、関連設定を削除します（取り消し不可）。サーバー側に保持するアカウントはありません。

Privacy Policy (Okure-nai)

Last updated: June 13, 2026

This policy describes how the macOS app Okure-nai (“the App”) handles information. The developer (“we”) does not operate a server that stores user accounts for the App.

1. Information and purposes

Data may be stored only on your Mac:

Type Examples Purpose
Sign in with Apple User identifier from Apple; email on first authorization if provided App sign-in as required by App Store guidelines
Google Calendar OAuth tokens; read-only calendar data as shown on Google’s consent screen Sync today’s events for alarms
Alarms & settings Times you set, sound toggle, auto-sync preferences Core functionality

2. Sharing and sale

We do not sell, rent, share, transfer, or disclose the data described above, including Google user data, to third parties. We do not use it for advertising, behavioral tracking, credit assessment, or any purpose unrelated to providing the App’s features.

Authentication information and requests required for Google Calendar integration are transmitted directly between the App and Google’s OAuth services, OpenID Connect service, and Google Calendar API at the user’s direction. They are not sent to our servers, advertising providers, analytics providers, data brokers, or other third parties. We make no other disclosures except where required by law.

3. Data protection

We use the following safeguards for sensitive data, including Google user data:

  • Authentication and API communications with Google use HTTPS (TLS), which encrypts data in transit.
  • OAuth tokens, calendar events retrieved for the current day, and related settings are processed only on the user’s Mac and are not stored on our servers.
  • The App runs within the macOS App Sandbox. Access to locally stored data is limited to the App and the user’s macOS account.
  • The App requests read-only Google Calendar access and retrieves only the current day’s events needed to create alarms.
  • Disconnecting Google Calendar or using “Delete account and data” removes OAuth tokens and related data stored by the App from the device.

4. Google OAuth

Calendar connection uses Google’s OAuth flow in the system browser. Please also refer to Google’s policies. Disconnecting in the App removes stored tokens from the device.

5. Managing Sign in with Apple

You can revoke access for this app in your Apple ID settings (e.g. via appleid.apple.com).

6. Account and data deletion

In Settings, “Delete account and data” removes Sign in with Apple data stored by the App, disconnects Google Calendar, deletes all alarms and related preferences on this Mac. This cannot be undone. There is no separate server account to delete.
